# Electrónica Analógica · Guía para aprobar

Guía de estudio (UPCT · GIEyA · 3.º curso · asignatura 507103006, curso 2026-27) pensada para estudiar desde cero:
operacionales (ideal y real), aplicaciones lineales y no lineales, Bode y filtros, cuadripolos y transistores en frecuencia.

- Veintiuna páginas con índice lateral global, como la guía de Control por Computador: Empezar (`index.html`, `empezar.html`), Parcial 1 (`tema-1-2.html` a `tema-6.html`), Parcial 2 (`tema-7.html`, `tema-8.html`, `realimentacion.html`, `potencia.html`), Practicar (`examen-2025-26.html`, `examenes.html`, `examenes-p2.html`, `fuen.html`, `problemas.html`, `calculadoras.html`, `autoevaluacion.html`) y Repasar (`formulario.html`, `glosario.html`, `plan.html`).
- `guia-completa.html`: toda la guía en una sola página (para buscar con Ctrl+F). También hay dos PDF: `Electronica-Analogica-guia-completa.pdf` (unas 240 páginas) y `Electronica-Analogica-formulario.pdf` (formulario de una hoja).
- `buscar.json`: índice del buscador, que encuentra texto en todas las páginas.
- Instalable como app (PWA): `manifest.webmanifest`, `sw.js` e iconos; funciona sin conexión tras la primera visita.
- `style.css` y `app.js` compartidos por todas las páginas.
- `img/`: diapositivas de clase usadas como figuras, cada una con su explicación paso a paso.

Para verla en línea hay que activar GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Material de estudio personal. Las diapositivas son de la asignatura (UPCT) y se muestran recortadas, sin pie ni logotipos.
